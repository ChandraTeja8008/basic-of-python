# Python Basics

A collection of beginner-friendly Python programs that demonstrate fundamental programming concepts such as arithmetic operations, loops, conditionals, strings, and number-based algorithms. This repository is intended for students and beginners learning Python.

## 📂 Project Structure

```
python basics/
│── Armstrong number.py
│── factorial.py
│── fibnocci.py
│── leap year.py
│── odd or even checker.py
│── palindrome.py
│── reverse a string.py
│── sum of two numbers .py
│── out puts .py
```

## 📌 Programs Included

### 1. Sum of Two Numbers
- Accepts two numbers from the user.
- Calculates and displays their sum.
- Includes input validation.

### 2. Odd or Even Checker
- Determines whether an integer is odd or even.
- Uses the modulus (`%`) operator.

### 3. Factorial Calculator
- Computes the factorial of a non-negative integer.
- Uses an iterative approach.

### 4. Fibonacci Sequence
- Generates the first **n** Fibonacci numbers.
- Handles edge cases such as `n = 0` and `n = 1`.

### 5. Leap Year Checker
- Checks whether a given year is a leap year.
- Implements the standard leap year rules.

### 6. Armstrong Number Checker
- Determines whether a number is an Armstrong number.
- Works for numbers with any number of digits.

### 7. Palindrome Checker
- Checks whether a given string is a palindrome.
- Ignores spaces and letter case.

### 8. Reverse a String
- Reverses a user-provided string.
- Demonstrates Python string slicing.

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/your-username/python-basics.git
```

2. Navigate to the project folder

```bash
cd python-basics
```

3. Run any Python program

```bash
python factorial.py
```

or

```bash
python "Armstrong number.py"
```
